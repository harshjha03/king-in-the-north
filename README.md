# Refined Portfolio

This is the readable project version of the Refined portfolio.

## Files

- `index.html` loads the app and local vendor scripts.
- `src/RefinedPortfolio.jsx` contains the actual Refined design, sections, navbar, and CSS.
- `src/data.js` contains the portfolio content.
- `assets/oath-bg.png` is the background image used by the contact section.
- `vendor/` contains the local React, ReactDOM, and Babel scripts extracted from the bundle.

## Run

From this folder:

```powershell
node .\serve.mjs
```

Then open:

```text
http://127.0.0.1:4173/
```
